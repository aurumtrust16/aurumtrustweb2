# 🧱 1) Database Design (PostgreSQL – Normalized)

## 🧑‍💼 1.1 customers

```sql
CREATE TABLE customers (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    full_name VARCHAR(255),
    phone VARCHAR(20) UNIQUE,
    line_user_id VARCHAR(100),
    email VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 📦 1.2 assets (ทรัพย์ที่นำมาจำนำ)

```sql
CREATE TABLE assets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    customer_id UUID REFERENCES customers(id),
    asset_type VARCHAR(50), -- gold, phone, watch, brandname
    title VARCHAR(255),
    description TEXT,
    brand VARCHAR(100),
    model VARCHAR(100),
    weight DECIMAL(10,2), -- for gold
    condition VARCHAR(50), -- new, good, fair
    estimated_price DECIMAL(12,2),
    actual_price DECIMAL(12,2),
    status VARCHAR(50) DEFAULT 'pending', -- pending, active, redeemed, expired
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 💰 1.3 pawn_transactions

```sql
CREATE TABLE pawn_transactions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    asset_id UUID REFERENCES assets(id),
    customer_id UUID REFERENCES customers(id),
    pawn_amount DECIMAL(12,2),
    interest_rate DECIMAL(5,2), -- %
    start_date DATE,
    due_date DATE,
    status VARCHAR(50) DEFAULT 'active', -- active, redeemed, defaulted
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 💵 1.4 payments (ดอกเบี้ย / ไถ่ถอน)

```sql
CREATE TABLE payments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    transaction_id UUID REFERENCES pawn_transactions(id),
    amount DECIMAL(12,2),
    payment_type VARCHAR(50), -- interest, redemption
    paid_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 🧾 1.5 inquiries (SEO lead + estimator)

```sql
CREATE TABLE inquiries (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    asset_type VARCHAR(50),
    detail TEXT,
    estimated_price DECIMAL(12,2),
    customer_name VARCHAR(255),
    phone VARCHAR(20),
    line_sent BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 🖼️ 1.6 asset_images

```sql
CREATE TABLE asset_images (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    asset_id UUID REFERENCES assets(id),
    image_url TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 🔐 1.7 users (admin/staff)

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(100) UNIQUE,
    password_hash TEXT,
    role VARCHAR(50), -- admin, staff
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```


# 🤖 4) Business Logic Layer (Important)

## 💰 Price Estimation Logic

```python
def estimate_price(asset_type, condition, weight=None):
    base_price = {
        "gold": 30000,
        "iphone": 10000
    }

    condition_factor = {
        "new": 1.0,
        "good": 0.8,
        "fair": 0.6
    }

    return base_price[asset_type] * condition_factor[condition]
```
